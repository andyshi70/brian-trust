# 智囊团（SAB）

> 把毛泽东、邓小平、Munger、Taleb 等 13 位思想家请到同一张桌子上，帮你把问题想透——然后把讨论压成一张下周就能干的行动卡。

## 顾问名单

**常驻四人（每场必到）**：

| 顾问 | 角色 | 在桌上干什么 |
|------|------|------------|
| 毛泽东 | 战略 / 弱者逆袭 | 查主要矛盾、逼一线调查、集中兵力打歼灭战（毛泽东思想 10 条方法论全套在列） |
| Munger | 逆向思维 | 先问"这事怎么死"，再谈怎么成 |
| Taleb | 风险 / 反脆弱 | 最坏情况会不会死，谁在扛尾部风险 |
| **邓小平** | 务实 / 改革与执行 | **永远最后发言收尾**：≤3 句话、末句必是问句、必须给出"花多少钱、多少天、验什么信号"（邓小平理论 13 条方法论全套在列） |

**按需顾问（1-3 位，按议题类型选，共 5-7 人出席）**：

Jobs【产品极致】· Buffett【价值/护城河】· Musk【工程极限】· 张一鸣【组织/算法】· Naval【杠杆/财富】· Paul Graham【创业/不可规模化】· Feynman【第一性原理】· Trump【谈判/筹码】· 南添【商业本质/现金流】

## 核心特色

- **结构化 6 阶段流程**：议题接收 → 信息补全 → 选席 → 发言与交锋 → 邓小平收尾 → 决议 + 行动卡
- **行动卡必出**：最小行动 / 预算上限 / 验证信号 / 放弃条件，四要素缺一不可——没有行动卡，本次讨论无效
- **人设不通融**：每位顾问有"三个框架 + 语气 DNA + 禁语表"，人设崩塌、互相附和、管理黑话（赋能/抓手/闭环）一律当场截断重说
- **自然张力对设计**：刻意安排观点碰撞（毛选歼灭战 vs 邓小平试点主义、Taleb vs Musk、Jobs vs 毛选），让分歧替你看见盲区
- **红牌机制**：Taleb / Munger 可当场亮红牌（最多 2 张），暂停辩论等用户回应致命风险后才能继续
- **决策日志闭环**：归档本次行动卡；下次开场自动引用上一次"最小行动 + 结果"，让智囊团对你执行的结果负责
- **HTML 可视化报告**（可选）：讨论结束一键生成交互式网页，手风琴发言卡 + 对话气泡交锋 + 风险地图

## 运行效果

```
Phase 0  议题接收    →  确认"你最担心的是什么"（可追问一句挖出），复述议题
Phase 1  信息补全    →  3-5 个关键澄清问题，必覆盖：客户是谁、预算/时间、最坏结果
Phase 2  选席        →  常驻四人 + 按需顾问，宣布名单与核心张力对
Phase 3  第一轮发言  →  每位顾问用自己的语气给判断（支持/反对/有条件），每人 ≤300 字
Phase 4  交锋        →  2-3 个分歧点深碰，每个分歧最多 2 轮；全场超 6 回合强制收敛
Phase 5  收尾+决议   →  邓小平收尾（3 问句模板）→ 共识/分歧/风险地图 + 【行动卡】
Phase 6  可视化报告  →  交互式 HTML 网页（可选）
```

## 触发方式

```
开智囊团，聊聊定价策略的问题
智囊团：要不要把个人 IP 转成公司化运营？
请 Taleb 和邓小平聊聊我这个 all-in 的想法
```

或直接用斜杠命令：`/sab`

## 安装

把本项目的 `SAB/` 复制到 Hermes 的全局 skills 目录：

```bash
# 全局（推荐）
mkdir -p ~/.hermes/skills
cp -r SAB ~/.hermes/skills/

# 或项目级：只对在该项目内启动的 Hermes 会话生效
cp -r SAB <项目根>/.hermes/skills/
```

装完重启 Hermes，然后说"开智囊团"或输入 `/sab`。

**建议开聊前**：建一个个人决策归档目录（技能默认写到 `00-我/decisions/`），这样「上次行动卡结果引用」的闭环才会生效；没有该目录也能正常讨论，只是跳过日志闭环。
