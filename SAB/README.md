# 私董会（Advisory Board）

> 把南添、Steve Jobs、毛泽东、邓小平、Trump、张一鸣、Paul Graham、Taleb、Naval、Feynman、Munger、Elon Musk、Buffett 请到同一张桌子上，帮你把问题想透。

## 核心特色

- **13 位顾问**，每位保持独特的语气、思维框架和说话方式
- **结构化 6 阶段流程**：议题接收 → 信息补全 → 选席 → 发言与交锋 → 邓小平收尾 → 决议（行动卡必出）
- **常驻四人 + 邓小平必收尾**：毛泽东、Munger、Taleb、邓小平每场必到；邓小平永远最后发言，把任何讨论压成一张可执行行动卡
- **自然张力对设计**：刻意安排观点碰撞（如 Taleb vs Musk、Jobs vs 毛选），产生深度洞察
- **红牌机制**：致命风险强制标注，确保不遗漏关键风险
- **HTML 可视化报告**：讨论结束后可一键生成交互式网页报告，白色背景、现代设计、手风琴卡片、对话气泡交锋

## 触发方式

```
私董会：要不要把个人IP转成公司化运营？
开私董会，聊聊定价策略的问题
请 Taleb 和 Musk 聊聊我这个 all-in 的想法
```

## 运行效果

```
Phase 0  议题接收     →  复述核心问题，判断议题类型
Phase 1  信息补全     →  以顾问视角提 3-5 个关键澄清问题
Phase 2  选席        →  选 5-7 位顾问，标明核心张力对
Phase 3  第一轮发言   →  每位顾问用自己的语气给出判断
Phase 4  交锋        →  2-3 个分歧点的深度碰撞
Phase 5  决议+行动卡 →  邓小平收尾（必出）+ 共识/分歧/风险地图 + 行动卡（必出）
Phase 6  可视化报告   →  生成交互式 HTML 网页（可选）
```

## 安装

把本项目的 `SAB/` 复制到 Hermes 的全局 skills 目录：

```bash
mkdir -p ~/.hermes/skills
cp -r SAB ~/.hermes/skills/
```

装完重启 Hermes，然后说"开私董会"，或直接输入 `/sab` 触发。

项目级安装则复制到 `<项目根>/.hermes/skills/SAB/`，只对在该项目内启动的 Hermes 会话生效。
