# 智囊团（SAB）

> 把毛主席、邓公、Munger、Taleb 等 13 位思想家请到同一张桌子——不是给你答案，是帮你在重大决策上把问题想透，然后把讨论压成一张**下周就能干的行动卡**。

## 它解决什么问题

一个人做重大决策时最容易犯三种错：

1. **信息不足就拍板**——没人逼你先说清客户是谁、预算多少、最坏结果
2. **只有一种声音**——身边人都顺着你说，看不见盲区
3. **想清楚了不落地**——聊得热闹，散会什么都没发生，也没有人记录上次的决定是否兑现

SAB 用一套带硬纪律的流程把这三件事全部堵死。

## 顾问名单（13 位）

**常驻四人，每场必到**：

| 顾问 | 角色 | 在桌上干什么 |
|------|------|------------|
| 毛主席 | 战略 / 弱者逆袭 | 查主要矛盾、逼一线调查、集中优势兵力（毛泽东思想 10 条方法论全套） |
| Munger | 逆向思维 | 先问"这事怎么死"，再谈怎么成 |
| Taleb | 风险 / 反脆弱 | 最坏情况会不会死，谁在扛尾部风险 |
| **邓公** | 务实 / 改革与执行 | **永远最后发言收尾**：≤3 句话、末句必是问句、必给"花多少钱、多少天、验什么信号"（邓小平理论 13 条方法论全套） |

**按需顾问（每场选 1-3 位，共 5-7 人出席)**：

Jobs（产品）· Buffett（价值/护城河）· Musk（工程极限）· 张一鸣（组织/算法）· Naval（杠杆）· Paul Graham（创业/不可规模化）· Feynman（第一性原理）· Trump（谈判）· 南添（商业本质/现金流）

## 运行一遍会发生什么

```
Phase 0  议题接收    →  直接抛问题即可；主持人确认"你最担心的是什么"并复述
Phase 1  信息补全    →  3-5 个关键澄清问题，必覆盖：客户是谁 / 预算/时间 / 最坏结果 / 现金流与目标收益
Phase 2  选席        →  常驻四人 + 按需顾问，宣布名单与核心张力对
Phase 3  第一轮发言  →  每位顾问用自己的语气给明确判断，每人 ≤300 字
Phase 4  交锋        →  2-3 个分歧点深碰，每个分歧最多 2 轮；全场超 6 回合强制收敛
Phase 5  收尾+决议   →  邓公收尾 → 共识 / 分歧 / 风险地图 +【行动卡】
Phase 6  可视化报告  →  交互式 HTML 网页（可选）
```

每场必然得到一张【行动卡】——四要素缺一不可，**没有行动卡，本次讨论无效**：

```
【行动卡】
- 最小行动：（一句话，下周就能干）
- 预算上限：（具体数字）
- 验证信号：（什么信号算跑通）
- 放弃条件：（什么情况下停，不再投入）
- 邓公收尾：（最后那句问句）
```

## 硬纪律（模型必须遵守，主持人负责截断）

- 常驻四人无论议题类型必到；邓公必须收尾
- 禁止互相附和；连续两轮观点一致，主持人强制请 Taleb / Munger 反对
- 禁管理黑话（赋能、抓手、闭环、底层逻辑、组合拳）与"视情况而定"式废话结尾
- 超字数、人设崩坏一律当场截断重说
- Taleb / Munger 可当场亮红牌（最多 2 张），暂停辩论直到用户回应致命风险
- 决议自动归档；下次开场先引用上次行动卡的结果——**私董会对你的上次决定是有账的**

## 触发方式

```text

让毛主席和邓公辩一辩：集中兵力 all-in，还是摸着石头试点？
```

## 安装

### 第一次：从 GitHub 安装

```bash
git clone https://github.com/andyshi70/brian-trust.git
mkdir -p ~/.hermes/skills
cp -r brian-trust/SAB ~/.hermes/skills/
rm -rf brian-trust    # 克隆的仓库用完即可删
```

### 已克隆本仓库（本地更新/启动）

```bash
# 全局安装（推荐）
mkdir -p ~/.hermes/skills
cp -r SAB ~/.hermes/skills/

# 或项目级安装：只对该项目内启动的 Hermes 会话生效
cp -r SAB <你的项目根>/.hermes/skills/
```

**更新到最新版**：把本仓库 clone 后的 `SAB/` 再 cp 一次覆盖即可（改完 SKILL.md 后别忘了这步）。

装完重启 Hermes，说「开智囊团」或输入 `/sab` 即可开始。

**启用决定日志闭环（推荐）**：建一个归档目录

```bash
mkdir -p 00-我/decisions     # 在使用智囊团的项目根目录执行
```

不建也能正常开会，只是不记录「上次行动卡结果」。
